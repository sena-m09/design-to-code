# 調整のしかた

SKILL.md の「調整」から読む。何回目の調整か、続けるか戻すかは `design-flow` が決めるので、ここでは 1 回の調整で何を直すかだけを扱う。

1. directive の `context.summaryPath` の `summary.json` を読む。`diffRatio` が差分の割合、`diffClustersCssPx` が差分の大きい範囲（CSS px、差分の大きい順）になる。
2. `context.comparePath` の `compare.png`（カンプ / 実装 / 差分を縮小して横に並べた画像）を見て、`diffClustersCssPx` の範囲で何が違うかを探す。原寸の `figma.png` / `actual.png` / `diff.png`（`summary.json` と同じディレクトリ）は、`compare.png` では判断できない微差を詰めるときだけ読む。
3. 上のほうの範囲から直す。上のセクションの高さがずれると、その下はすべてずれて差分に数えられるので、上を直すと下の差分もまとめて減ることが多い。
4. 1 回の調整では、原因と考えたことに絞って直す。複数の原因を一度に直すと、差分が減らなかったときにどれが悪かったか分からなくなる。

フォントの描画などの環境差は、閾値に収まる前提とする。環境差が原因と明らかな差分は、無理に詰めない。

対象外:

- 状態系（hover / focus / active 等）。初期表示状態のみを対象とする。
- 自動切替・トランジションを持つ動的セクション。初期表示が安定した静止状態を対象にする。
